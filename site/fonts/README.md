# New Hero font files go here

Upload the web-font versions (.woff2) with exactly these names. Any you don't have are skipped:

- NewHero-Regular.woff2
- NewHero-Medium.woff2
- NewHero-Bold.woff2
- NewHero-ExtraBold.woff2
- NewHero-Black.woff2

Until they're added, the page uses Montserrat, a free font with a similar look.
Note: this repository is public, so these files can be downloaded by anyone.
Only upload them if your font licence allows web use.
